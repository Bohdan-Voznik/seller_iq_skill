# SellerIQ skill для Claude

Скіл для Claude, який розуміє схему даних SellerIQ у Mixpanel (аналітика для продавців Rozetka) і дозволяє будувати довільні звіти й розрізи: продажі, юніт-економіка, позиції у видачі, реклама, залишки, конкуренти — а не лише один фіксований звіт.

## Встановлення

Потрібно завантажити собі **тільки один файл** — [`skill/SKILL.md`](./skill/SKILL.md). Решта (детальний опис кожної події, онбординг, рецепти) підтягується автоматично під час роботи з `raw.githubusercontent.com`, коли справді потрібно.

1. Завантаж `skill/SKILL.md` з цього репозиторію.
2. Постав його як скіл у Claude (Claude Code: `~/.claude/skills/selleriq/SKILL.md`, або відповідне місце для Claude.ai / іншого клієнта).
3. Переконайся, що в Claude увімкнено веб-доступ (fetch зовнішніх URL) — без цього довідкові файли не підтягнуться, і скіл працюватиме тільки на мінімальному наборі правил, вбудованому в `SKILL.md`.
4. Підключи Mixpanel MCP-конектор до проєкту SellerIQ (регіон конектора повинен збігатись з регіоном проєкту — `mcp.mixpanel.com` для US, `mcp-eu.mixpanel.com` для EU).

Перевстановлення `SKILL.md` потрібне лише коли змінюється сам цей файл. Оновлення довідкових файлів (`reference/*.md`) підхоплюються самі — кеш `raw.githubusercontent.com` близько п'яти хвилин.

## Структура репозиторію

```
seller_iq_skill/
  README.md                              ← цей файл
  skill/
    SKILL.md                             ← єдиний файл, який ставить користувач
  reference/
    index.json                           ← маніфест: версія, дата, список файлів і коли який підвантажувати
    core.md                              ← базові пастки трактування (завжди)
    order-item-snapshot.md               ← продажі, юніт-економіка, статуси замовлень
    product-position-snapshot.md         ← позиції у видачі, SERP
    extra-product-position-snapshot.md   ← конкуренти з 1-ї сторінки видачі
    ad-item-snapshot.md                  ← реклама, ДРР, CPO
    stock-snapshot.md                    ← залишки, швидкість продажів
    lookup-tables.md                     ← довідники products_crm / products_rozetka
    onboarding.md                        ← перше підключення
    recipes.md                           ← готові приклади розрізів і звітів
```

## Публічність

Репозиторій відкритий: семантика подій SellerIQ і логіка роботи скіла видимі всім. Це свідомий вибір — документація й так публічна, а оновлення розповсюджуються миттєво без участі користувача.
